# ایمیج بوتیک | Image Boutique Papeterie

نمونهٔ تعاملی فارسی/انگلیسی برای فروشگاه نوشت‌افزار و خدمات چاپ و صحافی. رابط با React و Vite ساخته شده است. این پروژه برای نمایش تجربهٔ سفارش است، نه ثبت پرداخت یا نگهداری سفارش واقعی.

## اجرا

با Node.js 22.12 یا جدیدتر از ریشهٔ مخزن اجرا کنید:

```sh
npm ci
npm run dev
```

نشانی نمایش‌داده‌شده در ترمینال را باز کنید. برای بررسی خروجی:

```sh
npm run build
npm run preview
```

## مسیرهای قابل بازبینی

- در فروشگاه محصولی باز کنید، آن را به علاقه‌مندی یا سبد اضافه کنید و صفحه را تازه‌سازی کنید.
- در بخش خدمات (`#/services`) اطلاعات یک سفارش آزمایشی چاپ را وارد کنید؛ از اطلاعات واقعی مشتری استفاده نکنید.
- زبان را تغییر دهید و جهت متن و نوار ناوبری موبایل را بررسی کنید.
- پیش‌نمایش ویرایش محتوا در `#/admin` یک پنل نمایشی است، نه مرز احراز هویت. پیش‌نویس‌ها، سبد و سابقهٔ سفارش نمونه در همان مرورگر می‌مانند؛ برای امتحان حالت خالی از یک نمایهٔ جدید استفاده کنید.
